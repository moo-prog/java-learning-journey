## 🏆 Featured Projects

These are the real, working projects I've built so far — not just exercises.

### 📚 Library Management System

A Java console app that manages books and members: add books, register members, borrow/return, and search by title. Built with Java and OOP (Inheritance, Interfaces, Abstract classes) plus Collections (ArrayList, HashMap). Later upgraded to use MySQL persistence via JDBC and the Repository pattern, so data survives a restart.

🔗 [Latest version (with MySQL)](week-04-sql/src/Libraryproject) &nbsp;·&nbsp; [Original OOP version](week-03-oop/src/Libraryproject)

### 💬 Quotes API

A REST API built with Spring Boot that serves, searches, and randomly picks inspirational quotes. Built with Java, Spring Boot 3, Maven, and Spring Web. Endpoints: `GET /api/quotes`, `GET /api/quotes/random`, `GET /api/quotes/search?author=...`

🔗 [View project](week-5-spring-boot) &nbsp;·&nbsp; [Project README](week-5-spring-boot/README.md)
