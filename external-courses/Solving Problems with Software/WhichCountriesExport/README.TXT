# Repository Description

This project analyzes international trade data from CSV files using Java and the **Apache Commons CSV** library. 

### Developed Functions:
* `countryInfo`: Finds and returns specific export details for any given country.
* `listExportersTwoProducts`: Prints all countries that export two specific products.
* `numberOfExporters`: Counts how many countries export a specific item.
* `bigExporters`: Lists countries with total export values greater than a specified amount.
