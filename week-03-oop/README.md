# My Library Project

This is a simple Java program for a school project. It helps to manage a library by saving books and members.

## What it can do:
* Add new books to the library.
* Add new members with their name and ID.
* Let members borrow a book or return it.
* Search for any book by typing its title.

## What I used in this project:
* Java language.
* OOP (like Inheritance, Interface, and Abstract class).
* Java Collections (ArrayList for books and HashMap for members).

## How to run it:
1. Open this project in IntelliJ IDEA.
2. Go to the file named `Main.java`.
3. Click the green play button to run it.
4. Type numbers (1 to 7) in the screen to choose what you want to do.
