* **Server:** A computer or software program that listens for incoming network requests and serves data or services to clients.

* **Request:** A message sent by a client (e.g., browser or HTTP client) to a server asking for data, a page, or an action to be performed.

* **Response:** The message sent back from the server to the client containing the status code and the requested data (or error information).

* **Framework:** A structured foundation or set of pre-written tools and libraries that provides a standard way to build applications faster.

* **Spring Boot:** An open-source Java-based framework used to create stand-alone, production-grade REST APIs and microservices quickly with minimal configuration.

* **Maven:** A build automation and project management tool for Java that handles project building, packaging, and dependency management via `pom.xml`.

* **Dependency:** An external library or package that your application relies on to function properly (e.g., Spring Web for building REST endpoints).
